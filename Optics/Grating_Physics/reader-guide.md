## Finding your way

The [homepage](index.md) gives the chapter overview, and the [Preface](preface.md) introduces the author and teaching approach. On a first reading, begin with [0.0: Foundations of scalar optics](0_0_Foundations_of_Scalar_Optics.ipynb) and follow the numbered sequence. Chapter 0 moves from fields and wave equations to boundaries, propagation and physical gratings.

Use the sidebar's collapsible topic groups to find a lesson. On smaller screens, open the navigation menu to see them. The page outline lists sections within a lesson; previous/next links follow the book's reading order. The original notebook numbering is retained.

## Reading a lesson

Start with the motivation and physical picture, then work through the equations and figures. Keep track of the quantities, units and conventions introduced in the lesson. If a derivation feels demanding, first identify its assumptions and conclusion, then return to the intermediate steps.

Treat each figure as a question you can investigate. Predict what will happen, change one parameter at a time, and compare the result with the explanation. Keep the model assumptions and numerical settings in view when comparing examples.

## Exercises and worked examples

Try a prediction or calculation before opening an expandable answer. Then compare your reasoning with the solution, including its assumptions and units. Answers and derivations can be expanded without starting Python.

Worked-example code provides another way to examine the reasoning. Reproduce the starting result before modifying it, and use any provided checks to assess your changes. The [Downloads page](Downloads.md) explains the available experiment collections and how to run them locally.

## Running the interactive examples

Text, equations and built figures are readable without a live Python session. To activate the examples on a lesson page:

1. Select the power button to connect to a Binder-backed Python session. No local Python installation is required.
2. Wait for the session to connect. Choose **Run all cells** if the examples have not run, then wait for execution to finish.
3. Use the sliders and other controls. If a reset control is provided, use it to return to the example's starting values.

Binder startup can take time. A new or restarted session may require running the cells again. If a control does not respond, check that the session is connected and its cells have finished executing.

For experiments you want to keep or extend, work with a local copy and save your changes there. Installation instructions, downloadable bundles and example commands are collected on the [Downloads page](Downloads.md).

## Questions and feedback

If an explanation seems unclear or a calculation behaves unexpectedly, note the lesson, parameter values and steps needed to reproduce the issue. Suggestions and corrections can be raised through the [public repository's issue tracker](https://github.com/ahariharan-hub/grating-physics-book/issues).
